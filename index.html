Export. Review. Import.

Export the page on one WordPress site and import it on another. The sites can use different hosts. No account or connection between them is required.

Step 1 / Staging

Export your page.

Open the page in the WordPress editor. Under PageFerry Export, click Export page to download the page and its media as a ZIP.

Step 2 / Destination

Review the import.

On the other site, go to Tools → PageFerry Import. Choose your ZIP and whether to create a draft or update an existing page. Click Review import and check the details.

Step 3 / Confirmation

Import the page.

Confirm the import. PageFerry updates image links and reuses matching files from the Media Library. Open the page in the editor and check it before publishing.

Check compatibility
Your images and media.
The ZIP includes the featured image and media used in the page. Image links are updated for the destination site. Files already in its Media Library are reused when their contents match exactly.
Create a draft or update a page.
Create a new draft or select an existing page to replace. Review the page details, keep or edit its URL slug, and choose what to import.
Categories, tags and custom fields.
Bring categories, tags and supported Advanced Custom Fields (ACF) values. Install the plugins or theme that provide your custom content types, categories and fields on the destination first.
Import results and previous versions.
Before updating a page, PageFerry saves a snapshot of its previous content and details. The result and import log show what was saved. Use the snapshot to restore values manually in WordPress.
No external import service.
Import directly into WordPress without an account or external service. Temporary files are stored in a private folder. Larger ZIPs can be prepared in your browser; file and total-size limits still apply.

Before you
import.

Compatibility, updates and file limits.

Read the plugin details
Will this move my whole website?

PageFerry moves one page, post or supported custom content type at a time. It does not transfer themes, plugins, site settings or an entire Media Library.

Can I update a page that is already live?

Yes. Select the page you want to update, review the changes and confirm. A published page stays published, so the changes appear on the live site. Its URL stays the same unless you edit the slug. A snapshot of the previous version is saved first.

Does it work with Elementor or other builders?

PageFerry supports the WordPress block editor (Gutenberg). Imports identified as Elementor, Divi, Beaver Builder, Bricks or WPBakery content are refused. Install the theme and custom block plugins needed to display the page on the destination first.

What happens to my images and ACF fields?

Media files are included in the ZIP. Matching Media Library files are reused when their contents match exactly. Newly added files keep their exported contents. If the site's upload rules would change a file, PageFerry stops and explains the conflict. Supported ACF custom field values move too, with updated image links. Install ACF and matching field definitions on the destination first. Field definitions, site-wide ACF options and SEO data are not included. Check fields that refer to other posts or users after importing.

Can I restore the page after an update?

Open Recovery snapshots to read the previous content and page details. Copy the values you need back into the WordPress editor. Restoration is manual; there is no one-click restore button.

What if my ZIP exceeds the upload limit?

Your browser can prepare a larger ZIP and upload its media files one at a time. Each file must still fit the upload limit, and the whole import must fit PageFerry’s size limits. Reduce an oversized file and export again, or ask your host to raise a lower upload limit.
